## Dalamud Quick Launcher v0.2.0

- ランチャー右クリックメニューに「Dalamud Quick Launcher を無効化」を追加しました。
- アイテムの説明、アクション詳細、ツールチップ、右クリックメニューなどが表示された際、実際に重なっているDQLアイコンだけ一時的に非表示にする処理を追加しました。
- 説明やメニューを閉じると、非表示になっていたアイコンは自動で再表示されます。
- FF14標準UIとの重なり時に、DQLの背景や外枠が邪魔になりにくいよう描画処理を調整しました。
- 設定 → ランチャーウィンドウに「ランチャー全体の不透明度」を追加しました。
- 通常時からアイコン・背景・外枠をまとめて透過できます。
- 既存の背景透明度設定は「背景だけの不透明度」に名称を変更しました。
- 右クリックメニューと設定画面は、操作しにくくならないようランチャー全体の透過対象外です。
