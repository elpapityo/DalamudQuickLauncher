# Dalamud Quick Launcher v0.2.0

Dalamudにインストール済みのプラグインと、任意のDalamudコマンドをゲーム内の小型ランチャーから呼び出すプラグインです。

## 主な機能

- インストール済みプラグイン一覧から表示するものだけを選択
- プラグイン標準アイコン / FF14ゲームアイコン / PNGを使用可能
- FF14ゲームアイコンは画像一覧から選択可能（Icon ID手入力にも対応）
- 左クリック / 右クリック / ホイール押し込みの操作に対応
- DQL管理メニューから並び替えモード、セット切替などを操作
- DQL本体アイコンの表示 / 非表示
- 管理用先頭アイコンと操作割り当て
- ランチャーセットを複数保存・切替
- 縦×横グリッド、アイコンサイズ、間隔、透明度、外側余白、背景色、外枠を調整
- ランチャー全体の不透明度を調整可能
- アイテムの説明、アクション詳細、ツールチップ、右クリックメニューなどと重なったDQLアイコンを一時的に非表示
- ランチャー右クリックメニューからDalamud Quick Launcher自体を無効化可能
- PNGパスはWindowsのファイル選択画面から指定可能
- ゲーム内ヘルプタブを搭載

## v0.2.0 の主な変更

- ランチャー右クリックメニューに「Dalamud Quick Launcher を無効化」を追加
- アイテムの説明、アクション詳細、ツールチップ、右クリックメニューなどと重なったDQLアイコンを一時的に非表示にする処理を追加
- 説明やメニューを閉じると、非表示になったアイコンを自動で再表示
- FF14標準UIとの重なり時に、DQLの背景・外枠が邪魔になりにくいよう描画処理を調整
- 設定 → ランチャーウィンドウに「ランチャー全体の不透明度」を追加
- 通常時からアイコン・背景・外枠をまとめて透過できるように変更
- 既存の背景透明度設定を「背景だけの不透明度」に名称変更
- 右クリックメニューと設定画面は、ランチャー全体の透過対象外

## FF14ゲームアイコンの選択

「画像から選ぶ...」を押すと、FF14ゲームアイコンを画像で確認しながら選択できます。Icon IDの直接入力も利用できます。

## 管理用先頭アイコン

初期状態ではDQL本体アイコンが管理入口です。DQL本体アイコンを非表示にする場合は、「プラグイン」タブで任意のプラグインを「管理用先頭」に指定できます。管理用先頭に指定したプラグインでは、各マウス操作の割り当てを設定できます。

## ビルド

ZIPを展開し、直下の `build.bat` を実行してください。ローカルテスト配置先は `Z:\DalamudQuickLauncher\Current` です。
